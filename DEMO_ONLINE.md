# Panduan lokal pengganti demo lama Lab 05

Urutan Lab 05 sekarang memakai **Docker Desktop pada PC Windows dan PowerShell**. Mulai dari [modul mahasiswa lokal](MODUL_MAHASISWA.md) atau [PDF modul](MODUL_MAHASISWA.pdf), dengan [README lokal](README.md) sebagai pintu masuk.

Modul tersebut mencakup Dockerfile pertama, build/tag, run dengan environment variable, builder/runtime, `.dockerignore`, dan Docker Hub dari PC sendiri. Jangan memakai urutan lama dokumen ini sebagai petunjuk praktik.

Untuk multi-container, lanjutkan [modul lokal Lab 06](https://github.com/SeedFlora/meet6CloudService/blob/main/MODUL_MAHASISWA.md). Kebijakan kelas tetap latihan formatif dan satu proyek kelompok 3 orang, dengan checkpoint minggu 7 serta hasil akhir minggu 14.
